⚠️ Open Design Flags
HIGH
F-1 — GameButton gradient is a base64 SVG data URI
The radial gradient is not tokenized — impossible to update via theme.css. Extract to CSS radial-gradient() token or /src/imports/ SVG asset.
MED
F-2 — No --font-mono token
tabular-nums alignment achieved via fontVariantNumeric inline style only. Add --font-mono token and .tabular-nums utility class.
MED
F-3 — max-width 2px drift
CommandCenter uses max-w-[1312px], GameHeader uses max-w-[1310px]. Unify to --max-w-page: 1312px CSS token.
MED
F-4 — No elevation ladder
All shadows are ad-hoc per component. Define 4-step --shadow-elev-{0–3} token set in theme.css.
MED
F-5 — Button pill radius conflict
GameButton uses 46px, PrimaryCTA uses 9999px. Unify under --radius-pill: 9999px token.
LOW
F-6 — fontVariantNumeric applied inline only
Should be a reusable .tabular-nums Tailwind utility or CSS class for consistency.
