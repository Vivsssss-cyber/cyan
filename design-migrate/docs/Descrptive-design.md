# Startup Valley Design DNA

## Core Character

Startup Valley is a futuristic command-center interface for a simulation game. It should feel authoritative, dense, and operationally sharp rather than playful or marketing-led.

## Visual Priorities

- Cool navy and teal foundations with a single cyan accent
- Glass-surface cards over a muted grid canvas
- Medium-high UI density with disciplined breathing room
- Asymmetric layouts instead of symmetric dashboard grids
- Heavy numeric emphasis with tabular figures

## Brand Rules

- Primary accent: `#00C1EB`
- Deep ink: `#002C33`
- Background canvas: `#eff2f4`
- Glass card fill: `rgba(255,255,255,0.6)`
- Structural border: `#C8DDE6`
- Positive: `#156162`
- Warning: `#B45309`
- Negative: `#c65252`

## Typography

- Primary font family: `Outfit`
- Numeric data should use tabular numerals
- Headings are tight, bold, and slightly negatively tracked
- Dashboards should not use serif fonts

## Composition Rules

- Prefer grid-based sections over generic card stacks
- Avoid three equal dashboard columns when an asymmetric split can communicate hierarchy better
- Keep content cards at 16px radius and 20px padding by default
- Use pills for high-level controls, status labels, and primary CTAs

## Banned Patterns

- Purple outside charts
- Pure black
- Floating labels
- Glassmorphism excess beyond the established card treatment
- Generic AI dashboard tropes like repeated equal cards and decorative sparklines with no meaning
